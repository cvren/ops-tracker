## Known limits carried into v0.6.0 start

- `UNASSIGNED_STALE` still uses task `createdAt` instead of a dedicated `unassignedSince` timestamp
- Delivery is still bounded to one derived email channel; there is no multi-channel matrix or digest model
- `v0.5.0` still does not include an advanced escalation builder, forecasting, BI, org hierarchy, or a generic rule engine

## Architectural constraints to preserve

- Keep `CommitmentPolicy` bounded to the fixed `v0.5.0` contract unless a new contract explicitly widens it
- Keep `ExceptionCase` as the source-of-truth work object for exceptions
- Keep delivery derived from the exception ledger instead of inventing a parallel truth
- Keep hosted-CI claims tied to actual pushed refs
- Start `v0.6.0` docs-first before widening scope
